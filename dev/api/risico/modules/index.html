Modules§

angstrom
Angström index, from temperature and relative humidity. No memory: store the input, then read output.
fosberg
Fosberg Fire Weather Index, from temperature, humidity and wind. No memory: store the input, then read output.
functions
fwi
The Canadian Fire Weather Index System (FFMC, DMC, DC, ISI, BUI, FWI).
hdw
Hot–Dry–Windy Index: vapour pressure deficit times wind speed. No memory: store the input, then read output.
kbdi
Keetch–Byram Drought Index.
mark5
McArthur Forest Fire Danger Index, Mark 5, with its drought factor.
nesterov
Nesterov ignition index: a cumulative dryness index reset by rain.
orieux
Orieux index: Thornthwaite evapotranspiration, soil water reserve and a fire danger class from 0 (low) to 3 (extreme). Each cell needs its heat index.
risico
RISICO: hourly dead fine fuel moisture, rate of spread and fireline intensity.
sharples
Sharples fuel moisture index and fire danger index. No memory: store the input, then read output.
