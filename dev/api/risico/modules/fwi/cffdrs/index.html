Module cffdrs 

Source
Expand description

Canonical daily Canadian Forest Fire Weather Index System (model_version: cffdrs).

Equations: Van Wagner, C.E. 1987, Development and structure of the Canadian Forest Fire Weather Index System, Forestry Technical Report 35 (equation numbers below), and Van Wagner, C.E. & Pickett, T.L. 1985, Equations and FORTRAN program for the Canadian Forest Fire Weather Index System, Forestry Technical Report 33. The implementation follows the reference R package cffdrs (https://github.com/cffdrs/cffdrs_r, R/fine_fuel_moisture_code.r, R/duff_moisture_code.r, R/drought_code.r, R/initial_spread_index.r, R/buildup_index.r, R/fire_weather_index.r, R/fwi.r) line by line, including its latitude adjustment of the day-length factors and its constraints (RH >= 100 is taken as 99.9999, temperature floors of -1.1 C for the DMC and -2.8 C for the DC, rain-phase DC floored at 0).

The daily step uses the weather at local standard noon (temperature [C], relative humidity [%], 10 m wind [km/h]) and the rain of the 24 hours ending at that noon [mm]; see update_state_cffdrs in functions.rs for how hourly or 3-hourly forecasts are turned into those values.

All arithmetic is done in f64; the state is stored in f32.
